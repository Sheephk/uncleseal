網頁編寫 RTSP 連結技術指南

主題：如何在網頁中嵌入與處理 IP Camera 的 RTSP 串流

原始需求網址：
rtsp://rtsp:BGKlEhnR@192.168.15.24:554/av_stream/ch0

一、 核心問題說明

在標準的網頁（HTML5）中，如果直接使用普通的超連結標籤：

<a href="rtsp://rtsp:BGKlEhnR@192.168.15.24:554/av_stream/ch0">觀看攝影機畫面</a>

結果：現代瀏覽器（如 Chrome、Edge、Safari、Firefox）基於安全與架構原因，原生並不支援直接播放 RTSP 串流。使用者點擊後，瀏覽器通常會毫無反應，或者彈出提示要求尋找外部應用程式（如 VLC）來開啟。

二、 解決方案與實作方法

方案 1：直接呼叫本地 VLC 播放（免架伺服器，適合內部測試）

如果只是想做一個簡單的超連結，讓內部人員點擊。可以直接把網址寫在 <a> 標籤。但觀看者需要複製該連結，貼到 VLC Media Player（媒體 -> 開啟網路串流）中觀看，或是電腦需要註冊 URL Protocol 偽協定來觸發本地播放器。

方案 2：利用 MediaMTX 進行後端轉碼（推薦，可在網頁直接觀看）

現行現代網頁的主流做法，是透過輕量級媒體伺服器將 RTSP 轉成瀏覽器看得懂的 WebRTC 或 HLS 訊號。

MediaMTX 安裝與設定步驟：
  • 下載： 前往 GitHub 下載 mediamtx_windows_amd64.zip 並解壓縮。
  • 設定檔案： 打開 mediamtx.yml，捲動到最底部 paths: 區段，新增以下內容： 
    paths:
  cam1:
    source: rtsp://rtsp:BGKlEhnR@192.168.15.24:554/av_stream/ch0
  • 啟動： 雙擊執行 mediamtx.exe（請保持視窗開啟）。

方案 3：網頁前端嵌入程式碼

當 MediaMTX 在後端轉碼成功後，你就可以直接在你的 HTML 網頁（例如：小海豹歡樂天地）中，使用 <iframe> 標籤將即時監控畫面嵌入進去：

<!-- 嵌入 WebRTC 畫面到網頁中（幾乎零延遲） -->
<iframe 
    src="http://localhost:8889/cam1/" 
    width="640" 
    height="480" 
    frameborder="0" 
    scrolling="no" 
    allowfullscreen>
</iframe>

三、 疑難排解（若 MediaMTX 無法執行）

  • 避免閃退： 不要直接雙擊打開，請先開啟 CMD (命令提示字元)，切換至該目錄並輸入 .\mediamtx.exe 執行，才能看清錯誤訊息。
  • 格式檢查： mediamtx.yml 的縮排絕對不能使用 Tab 鍵，只能使用「空白鍵」。
  • 連接埠衝突： 若出現 address already in use，代表預設的連接埠（如 8554、8888）被其他監控或直播軟體佔用，需進入 yml 檔修改對應的 Port。
